Comrade.load_array_txt Function
julia
load_array_txt(path)

Read an ehtim-style antenna text file and return a dictionary keyed by site symbol. Each value is a NamedTuple with the columns present in the file: (SEFD1, SEFD2, fr_parallactic, fr_elevation, fr_offset) plus the d-term fields (DR, DL) if present. fr_offset is converted from degrees (the ehtim file convention) to radians.

The file must begin with a commented header naming the columns, e.g.

julia
# site  X  Y  Z  SEFDR  SEFDL  DR_RE  DR_IM  DL_RE  DL_IM  FR_PAR  FR_ELEV  FR_OFF

Columns are matched by name (case-insensitive), so the order of fields and the relative position of the D-term and FR blocks are flexible. X, Y, Z are ignored here — antenna positions come from the uvfits AIPS-AN table. The result can be passed to any extract_* as array_overrides=load_array_txt("array.txt").

julia
reset_mounts!(dvis::AbstractObservationTable, overrides)
reset_mounts!(dvis::AbstractObservationTable, file::String)

Update the mount-related columns of dvis's array table in place from a per-site overrides dict. Each entry is a Symbol => NamedTuple whose keys may be any of :SEFD1, :SEFD2, :fr_parallactic, :fr_elevation, :fr_offset. Missing keys keep the existing value.

Comrade.@sky Macro
julia
@sky function name(grid; kwargs...)
    param₁ ~ dist₁
    param₂ ~ dist₂
    # ... model body using params and kwargs ...
    return AbstractModel
end

Define a SkyModel constructor in a single block. Each name ~ dist line contributes an entry to the prior NamedTuple; everything else becomes the model body. The macro emits three definitions in the calling module:

  • _<name>_sky(θ, metadata) — the model function passed to SkyModel.

  • _<name>_prior(; kwargs..., grid) — builds the prior NamedTuple.

  • <name>(grid; kwargs...) — the user-facing constructor, returning a SkyModel.

The first positional argument is the image grid. Keyword arguments are stored in the model metadata (along with the grid) and are in scope for both the prior RHS expressions and the model body. The metadata destructure inside the model body only unpacks names that the body actually references.

Hierarchical priors

The RHS of ~ is any Julia expression evaluated in the prior-builder's scope. Use this to plug in pre-built compound priors:

julia
@sky function imager(grid; ftot, mimg, cprior)
    c    ~ cprior                                       # e.g. HierarchicalPrior or corr_image_prior
    σimg ~ VLBITruncated(VLBIGaussian(0.0, 0.5); lower = 0.0)
    fg   ~ VLBIUniform(0.0, 1.0)
    ρs   ~ ntuple(Returns(VLBIUniform(0.01, 10.0)), 3)  # tuple-of-IID priors
    rast = apply_fluctuations(CenteredLR(), mimg, σimg .* c.params)
    pimg = parent(rast)
    @. pimg = (ftot * (1 - fg)) * pimg
    return ContinuousImage(rast, BSplinePulse{3}())
end

Conditional priors where one tilde RHS references another tilde's drawn value are not supported directly. Express such cases by wrapping the chain in a HierarchicalPrior on a single tilde RHS — HierarchicalPrior nests, so HierarchicalPrior(base, HierarchicalPrior(...)) covers arbitrary-depth hyperprior chains.

Comrade.AbstractSkyModel Type
julia
AbstractSkyModel

The abstract type for Comrade Sky Models. For a concrete implementation see SkyModel.

Any subtype must implement the following methods

  • ObservedSkyModel(m::AbstractSkyModel, array::AbstractArrayConfiguration): Constructs an observed sky model given the sky model m and the array configuration array. This method is used to compute the visibilities and image of the sky model.

The following methods have default implementations:

  • idealmaps(datatype, m::AbstractSkyModel, x): Computes the ideal intensities and visibilities of the sky model m given the model parameters x.

  • skymodel(m::AbstractSkyModel, x): Returns the sky model image given the model parameters x.

  • domain(m::AbstractSkyModel): Returns the domain of the sky model m.

  • set_array(m::AbstractSkyModel, array::AbstractArrayConfiguration): Sets the array configuration for the sky model m and returns the observed sky model and prior.

  • set_prior(m::AbstractSkyModel, array::AbstractArrayConfiguration): Sets the prior for the sky model m given the array configuration array. This is used to set the priors for the model parameters.

Comrade.SkyModel Type
julia
SkyModel(f, prior, grid::AbstractRectiGrid; algorithm = NFFTAlg(), metadata=nothing)

Construct a sky model using the function map f with parameter priors prior, where the image model is defined on the domain grid. If the underlying model produced by f is non-analytic, then algorithm is used to numerically Fourier transform the model image. The metadata option contains additional information needed by the model f.

Arguments

  • f(x, p) : A function must be two arguments, where x are the model parameters and p is the metadata. typically x and p are named tuples.

  • prior : A named tuple of priors for the model parameters defined in x. Each model parameter used in x must have a defined element in the prior.

  • grid : The domain on which the model is defined. This defines the field of view and resolution of the model. Note that if f produces a analytic model then this field of view isn't used directly in the computation of the visibilities.

Optional Arguments

  • algorithm : The Fourier transform algorithm used to compute the visibilities. The default is NFFTAlg() which uses a non-uniform fast Fourier transform. Other options can be found by using subtypes(VLBISkyModels.FourierTransform)

  • metadata : Additional information needed by the model f. These are the addtional arguments passed to the model function f.

Define an InstrumentModel constructor in a single block, mirroring @sky. Each Jones term is built with a @jones block, which carries its own ~ priors and param_map; the priors of all blocks are collected into the instrument prior. The body then composes the built Jones terms (e.g. with JonesSandwich) and returns the result.

The instrument model takes no positional arguments. Keyword arguments are tunable constants in scope for the ~ prior expressions and the @jones bodies. refbasis is treated specially: it is forwarded only to InstrumentModel and defaults to CirBasis() if not listed. Priors are declared only inside @jones blocks — a top-level ~ is an error. ~ lines are optional overall, so a parameter-free response model is allowed.

The JonesSandwich combination function is lifted to a named function automatically (named functions, unlike closures, serialize reliably).

Example:

julia
@instrument function fullpol(; refbasis = CirBasis(), gain_std = 0.1, dterm_std = 0.2)
    G = @jones begin
        lgR   ~ ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, gain_std)))
        gpR   ~ ArrayPrior(IIDSitePrior(ScanSeg(), DiagonalVonMises(0.0, inv(π^2)));
                           refant = SEFDReference(0.0), phase = true)
        lgrat ~ ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, gain_std)))
        gprat ~ ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, 0.1)))
        gR = exp(complex(lgR, gpR))
        gL = gR * exp(complex(lgrat, gprat))
        return JonesG((gR, gL))
    end
    D = @jones begin
        dRx ~ ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, dterm_std)))
        dRy ~ ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, dterm_std)))
        dLx ~ ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, dterm_std)))
        dLy ~ ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, dterm_std)))
        return JonesD((complex(dRx, dRy), complex(dLx, dLy)))
    end
    R = @jones begin
        return JonesR(; add_fr = true)
    end
    return JonesSandwich(G, D, R) do g, d, r
        adjoint(r) * g * d * r
    end
end

Comrade.GaussMarkovSitePrior Type
julia
GaussMarkovSitePrior(seg::TimeSegmentation, process::AbstractGaussMarkovProcess; init = StationaryInit(), param = NonCentered())

A site prior correlated in time, following the continuous-time Gauss-Markov process (e.g. OrnsteinUhlenbeck) at the times given by the segmentation seg. The log-density factorizes over each site's time chain using the process's exact discretization, so it costs O(n) in the number of times and handles irregular time sampling exactly. With multiple frequency channels, each (site, channel) pair is an independent chain.

Process fields that are Distributions.Distributions are fitted hyperparameters. When any are present the prior sample is a NamedTuple (params = SiteArray, hyperparams = NamedTuple), as for HierarchicalPrior; otherwise the sample is a plain SiteArray. Each site gets its own hyperparameters: the process passed to ArrayPrior is a per-site template, and each site's fitted fields are nested under the site's name (e.g. x.instrument.lg.hyperparams.AA.σ). The usual ArrayPrior per-site overrides replace the template, or the whole prior, for that site. caltable/plotcaltable accept the hierarchical sample directly; for elementwise postprocessing use the params field, e.g. exp.(x.instrument.lg.params).

Parameterization

The param keyword picks the chain's latent coordinates: NonCentered, Centered, or, for wrapped processes only, AngleEmbedded. centered = true / centered = false is shorthand for Centered() / NonCentered(); passing both param and centered throws. The default is NonCentered for every process that supports it, which is all of them except WrappedOrnsteinUhlenbeck.

Centered coordinates give the sampler the chain's prior correlation. For a random walk the condition number of that correlation grows with the number of time stamps, and a diagonal mass matrix cannot absorb it. A common shift of one station's whole phase chain, which trades against source position and structure, is then a diagonal direction through every coordinate of the chain; in non-centered coordinates it is a single coordinate (the chain's level), and the increments are prior-standardized. Centered can mix better when every point is strongly constrained by the data and the prior is weak.

For a real-line process (OrnsteinUhlenbeck, BrownianMotion), NonCentered also removes the funnel between fitted hyperparameters and gains and makes the transport to the Std spaces exact, so both asflat and ascube work. Centered supports asflat only.

For a wrapped (circular) process every parameterization supports asflat only. The chain density is 2π-periodic, so a real coordinate read directly as an angle gives an improper flat target, with identical modes spaced 2π apart in every coordinate. Centered and NonCentered therefore multiply each free phase's flat density by the sheet weight N(δ; 0, Q) / WN(δ; Q), where δ is its step from the previous chain value and Q that step's variance. The weights sum to one over the 2π sheets, so the circular model is unchanged while the flat target becomes proper; a 2π step costs exp(−(2π)²/2Q).

Under Centered the flat target is the unwrapped Gaussian random walk in the raw angles. Under NonCentered each free phase's coordinate is its increment divided by the step's standard deviation, the flat target is N(0, I) in those coordinates, and the phase is the wrapped running sum. In both, the chain's first free point keeps a raw-angle coordinate. For a non-centered wrapped chain, logprior of a constrained sample contains only the chain-opening terms, and the rest of the density is in the flat transform's log-Jacobian; only their sum, which samplers and optimizers evaluate, is the chain density. On the circle NonCentered requires a transition mean that carries the previous point's sheet: WrappedBrownian (Φ ≡ 1) or the 2π-equivariant sine drift of VonMisesProcess, whose recurrence is resolved sequentially. The shortest-arc drift of WrappedOrnsteinUhlenbeck does not, so that process is Centered only.

AngleEmbedded embeds each free phase as two latent reals through the angle transform of DiagonalVonMises. It has no sheet structure (a phase wrap is a continuous winding of the latent point), at the cost of twice the phase dimension, a per-pair geometry that a diagonal mass matrix cannot capture, and the chain correlation of the centered form.

Phases

For an absolute phase use WrappedBrownian with init = UniformInit(): the prior is 2π-periodic, needs no separate circular offset term, and its coherence-time posterior is not biased by phase wraps. For a phase held near a level, such as an R/L gain ratio phase, use WrappedOrnsteinUhlenbeck, whose WN(μ, σ²) marginal keeps the chain from wandering. A real-line process (e.g. OrnsteinUhlenbeck with init = FixedInit(0.0) on top of a circular offset) models the phase as an unwrapped real and is appropriate only when excursions stay well below 2π; larger excursions produce 2π-shifted posterior modes from the likelihood's periodicity in exp(iθ). The phase = true option of ArrayPrior is not supported with this prior and throws.

Initial distribution

init (see AbstractInitialPrior) sets the distribution of each chain's first time stamp. StationaryInit (the default) uses the process's stationary marginal. GaussianInit uses an explicit N(μ0, σ0²), e.g. a wide one so the starting value is nearly free. FixedInit conditions the chain to an exact value at its first time, the continuous-time analogue of phase = true. For an unwrapped phase chain on top of a separate circular offset, FixedInit(0.0) removes the level freedom that would otherwise trade against the offset and, through the likelihood's 2π periodicity, produce 2π-shifted posterior modes. If the reference scheme also fixes a chain's first point, the two values must agree, or construction throws.

Reference stations

On the real line a reference-fixed value is a value of the process, and the free points are drawn from p(free | fixed) exactly. Scattered fixed indices, such as those from SEFDReference, are supported.

On the circle a reference-fixed value is a gauge choice. A station's phase is defined only up to the per-time global phase that the reference scheme removes, so being the reference says nothing about the station's own gain phase, and conditioning on it would pull the station's whole chain toward the reference value. A wrapped chain is therefore built over the time stamps where the station is free, with transitions taken over the combined gap across skipped stamps: a point after a reference-fixed stamp is an offset from the last free point. The fixed values still enter the likelihood but carry no prior term. For WrappedBrownian this chain is the exact marginal of the full one.

Example

julia
lg ~ ArrayPrior(GaussMarkovSitePrior(IntegSeg(), OrnsteinUhlenbeck(σ = VLBIExponential(0.1), τ = VLBIExponential(2.0))))
gp ~ ArrayPrior(GaussMarkovSitePrior(ScanSeg(), OrnsteinUhlenbeck(σ = 3.0, τ = 1.0)); refant = SEFDReference(0.0))
## phase-fluctuation term meant to be combined with a circular per-track offset
dgp ~ ArrayPrior(GaussMarkovSitePrior(ScanSeg(), OrnsteinUhlenbeck(σ = 1.0, τ = 1.0); init = FixedInit(0.0)); refant = SEFDReference(0.0))

Note

The example uses the VLBI* distributions (VLBIExponential, VLBIInverseGamma, ...) for fitted hyperparameters. These accept a scalar traced argument and so work on both the CPU and GPU/Reactant backends; the plain Distributions.jl types work only on the CPU.

Comrade.WrappedBrownian Type
julia
WrappedBrownian(; τ)

Brownian motion on the circle: angular increments over a gap Δt (hours) are wrapped normal WN(0, 2Δt/τ), the wrap of BrownianMotion onto (−π, π]. Use it for gain phases: the prior is 2π-periodic, so 2π-shifted posterior modes are equivalent (the likelihood sees only exp(iθ)), and the coherence-time posterior is not biased by phase wraps.

In the visibility domain the process decorrelates exponentially, E[e^{i(θ(t+Δ) − θ(t))}] = e^{−Δ/τ}, so τ is the phase coherence time in hours (the diffusion coefficient is D = 2/τ rad² per hour). The circular stationary law is uniform, so with UniformInit the chain also absorbs the per-track phase offset and no separate circular offset term is needed.

The transition mean is the previous phase, so this process supports param = NonCentered() (the default): each free phase's coordinate is its increment divided by the step's standard deviation, and the phase is the wrapped running sum. param = Centered() uses the raw angles. Both use sheet weights to keep the flat target proper without changing the circular model; AngleEmbedded avoids them at twice the phase dimension. Only asflat is supported. See GaussMarkovSitePrior.

A reference-fixed time stamp is a gauge choice, so it is dropped from the chain and the free points step over the combined gap (wrapped normal transitions compose: their variances add). A reference station's phases at other times are offsets from its last free phase, not pulled toward the reference value.

Arguments

  • τ: the phase coherence time in hours (the times of a VLBI observation are in UTC hours): the gap over which the visibility-domain coherence E[e^{iΔθ}] falls by 1/e. Pass a Number to fix it or a Distributions.Distribution to fit it as a hyperparameter with that prior.

Comrade.WrappedOrnsteinUhlenbeck Type
julia
WrappedOrnsteinUhlenbeck(; σ, τ, μ = 0.0)

The mean-reverting process on the circle: the wrap of OrnsteinUhlenbeck onto (−π, π], with the drift taken along the shortest arc so that the law is 2π-periodic in both of its arguments and is a circular Markov kernel,

julia
θ(t + Δt) | θ(t) ~ WN(μ + φ*wrap(θ(t) - μ), σ²*(1 - φ²)),   φ = exp(-Δt/τ),

where wrap maps to (−π, π]. Its circular marginal is the wrapped normal WN(μ, σ²), so, unlike WrappedBrownian, the phase stays near a level, and the visibility-domain coherence

julia
E[e^{i(θ(t+Δ) − θ(t))}] = exp(−σ²(1 − e^{−Δ/τ}))

levels off at exp(−σ²) rather than decaying to zero. Taking σ, τ → ∞ at fixed 2σ²/τ = 2/τ_coh recovers WrappedBrownian(τ = τ_coh).

Use it for a gain ratio (R/L) phase, an instrumental offset that is stable up to slow drift: one chain replaces a WrappedBrownian chain with FixedInit plus a separate circular offset, and σ sets how far the ratio phase may stray. The shortest-arc drift drops the previous phase's sheet, so this process supports only param = Centered() and asflat; VonMisesProcess is a non-centered alternative. As for every wrapped process, reference-fixed time stamps are dropped from the chain. See GaussMarkovSitePrior.

Arguments

  • σ: the circular marginal spread in radians, i.e. the WN(μ, σ²) scale. Pass a Number to fix it or a Distributions.Distribution to fit it as a hyperparameter.

  • τ: the reversion timescale in hours (the times of a VLBI observation are in UTC hours), the same units as the τ of OrnsteinUhlenbeck and WrappedBrownian. A Number fixes it; a Distributions.Distribution fits it.

  • μ: the circular mean (default 0.0). Not fittable.

Valid for σ well below π

Three properties hold only up to the WN(μ, σ²) mass beyond μ ± π: stationarity of the marginal, exact composition of the reference-antenna conditioning of GaussMarkovSitePrior over skipped time stamps, and continuity of the kernel at the antipode of μ. That mass is 1.7e-3 at σ = 1 rad and e^{-123} at σ = 0.2 rad. Do not use this process as an uninformative circular prior (σ ≳ 2); use WrappedBrownian with UniformInit instead.

julia
VonMisesProcess(; σ, τ, μ = 0.0)

The mean-reverting circular process with a smooth drift. It has the same σ, τ, μ, and transition variance σ²(1 − φ²), φ = exp(−Δt/τ), as WrappedOrnsteinUhlenbeck, with the shortest-arc drift replaced by the sine drift

julia
θ(t + Δt) | θ(t) ~ WN(θ(t) − (1 − φ)·sin(θ(t) − μ), σ²*(1 − φ²)),

a discretization of the von Mises (circular Langevin) diffusion, whose stationary law is vM(μ, 1/σ²) ≈ WN(μ, σ²) for small σ. For deviations well inside (−π, π) the two drifts agree (sin ε ≈ ε), so this process can replace WrappedOrnsteinUhlenbeck in the σ ≪ π regime, with the same warning: do not use it as an uninformative circular prior; use WrappedBrownian there.

The sine mean is smooth and 2π-equivariant in the previous point, whereas the shortest-arc drift jumps by 2πφ at the antipode of μ, so this process supports param = NonCentered() (the default), whose coordinates decouple the chain values from fitted hyperparameters and from each other. The drift also vanishes at the antipode, an unstable equilibrium where the stationary density is smallest; for σ ≪ π the chain almost never reaches it.

The drift is nonlinear, so a non-centered chain is resolved as a sequential recurrence rather than the batched affine scan; under Reactant this is a serialized loop. It suits scan-level chains, e.g. a gain ratio phase about a separate circular offset with init = FixedInit(0.0), or carrying its own level with the default StationaryInit. For an integration-level absolute phase use WrappedBrownian.

  • τ: the reversion timescale in hours (the times of a VLBI observation are in UTC hours). A Number fixes it; a Distributions.Distribution fits it.

  • μ: the circular mean (default 0.0). Not fittable.

Comrade.gauge_pins Function
julia
gauge_pins(terms, array::AbstractArrayConfiguration; prefer = default_gauge_preference)
gauge_pins(terms, stamps, sites_at, sefd; prefer = default_gauge_preference)

Return the entries that must be pinned, as a Vector{Tuple{Symbol, Int}} of (term name, entry index), so that a station phase written as the sum of terms is fully determined by the data. An empty result means the parameterization is already identified.

terms is a NamedTuple mapping each term's name to (; smap, fixed), where smap is the term's SiteLookup and fixed holds the entry indices that its referencing scheme and init pins hold constant. The first form reads the schedule off an array configuration. The second takes stamps, a vector of (time, frequency) pairs sorted by time; sites_at, the sites present at each stamp; and sefd, a site-keyed NamedTuple or dictionary of system equivalent flux densities. The sites of one stamp must be connected by baselines: a (time, frequency) whose baselines split into disconnected groups is listed once per group.

Each datum (site s at stamp τ) gives one equation relating the stamp's phase constant to the free entries covering (s, τ). An entry covers a datum when its site matches and its integration time and frequency channel contain the stamp. The solver:

  1. Removes each equation with three or more unknowns that contains an unknown appearing in no other equation, and marks that unknown as determined (a stamp constant if there is one, otherwise the least preferred entry). This repeats until no equation can be removed.

  2. Treats the remaining equations as graph edges: an equation with one unknown determines it, and one with two unknowns links them. A remaining equation with three or more unknowns throws an ArgumentError.

  3. Pins one entry in each connected group of unknowns that no equation determines, chosen by prefer; see default_gauge_preference.

A group containing only stamp constants needs no pin.

Notes

InstrumentModel applies this analysis, through its gaugefix setting, to the terms declared with gauge = :phase.

julia
default_gauge_preference(entry)

Rank the entries that gauge_pins may pin: the entry with the smallest key is the one it pins, and the largest key is the one it treats as determined when a datum can only determine one of its entries.

The key is (-dt, sefd, -occupancy): pin the entry with the longest integration time first, then the most sensitive site, then the site with the most data.

Comrade.InstrumentModel Type
julia
InstrumentModel(jones, prior; refbasis = CirBasis(), gaugefix = :error, selfcal = false)

Builds an instrument model using the jones matrix jones, with priors prior. The reference basis is refbasis and is used to define what the ideal basis is. Namely, the basis that you have the ideal visibilties to be represented in. For classical VLBI refbasis = CirBasis is a good default option, sinc the majority of the array uses circular feeds. For linear feed arrays like VGOS a user should switch to LinBasis, although failure to do so will not cause any errors, and is just a less efficient representation of the visibilities.

Arguments

  • jones : The jones matrix that represents the instrument. This is a function that takes in the parameters of the instrument and returns a jones matrix. See SingleStokesGain for a Stokes I example and JonesG or JonesD for polarized examples.

  • prior: A named tuple of ArrayPrior that specify what the priors are for each component used to construct the jones matrix using the function jones

Optional Arguments

  • refbasis: The reference basis used for the computation. The default is CirBasis() which are circular feeds.

  • gaugefix: What to do when the priors declared with gauge = :phase (see ArrayPrior) add up to a station phase the data cannot determine. :error (the default) throws, listing the entries that would fix it; :pin adds those entries to each affected prior's referencing scheme and logs one line per pin. The check uses Comrade.gauge_pins and runs when the model is given an array configuration.

  • selfcal: whether each station's common phase is written as φ = φ̂ + selfcal_residual, where φ̂ is the self-calibration solution. jones must then omit the station phase. See the section below.

Self-calibrated station phase

With selfcal = true, the model adds the instrument parameter selfcal_residual: one angle per station and data time, with prior WrappedNormal(0, 2π), whose density differs from the uniform density on the circle by a relative 2exp(-2π²) ≈ 5e-9 at most. In each group of stations that baselines link at one time and frequency, the station with the largest total data weight Σ 1/σ² is the reference, and its residual is fixed to 0. The priors of all other terms are those in prior.

φ̂ is the phase of the leading eigenvector of each group's Hermitian station matrix

julia
A_ij = Σ_p V_ij,p conj(M_ij,p) / σ²_ij,p      (i ≠ j)
A_ii = Σ_j Σ_p |M_ij,p|² / σ²_ij,p

where V and σ are the data and their noise, M the model visibilities without the station phase, and p runs over the correlation products. The off-diagonal part is the phase-dependent term of the Gaussian log-likelihood; the diagonal makes A positive semidefinite when the model matches the data. The eigenvector is approximated by A^32 e_r, 32 power iterations from the unit vector e_r of the reference station, so φ̂ is zero there.

φ̂ depends on the sky and the other instrument parameters but not on the residual, so the change of variables from φ to the residual has unit Jacobian. Because the prior is uniform on the circle, the prior of φ does not depend on φ̂, and the posterior is that of a uniform station phase. The residual is the station phase in coordinates that depend on the data, so compare or reuse draws through φ (selfcal_phase). Because φ̂ depends on the data, the model can only be used in a VLBIPosterior with one table of complex visibilities or coherencies.

Example

A Stokes I example is

julia
julia> G = SingleStokesGain(x->exp(complex(x.lg, x.pg)))
julia> intprior = (lg = ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, 0.1))),
            pg = ArrayPrior(IIDSitePrior(ScanSeg(), DiagVonMises(0.0, inv(π^2))))
            )

julia> intm = InstrumentModel(G, intprior)

A standard polarized example is

julia
julia> G = JonesG() do
        gR = exp.(complex(x.lgr, x.gpr))
        gL = gr*exp.(complex(x.lgrat, x.gprat))
        return gR, gL
    end
julia> D = JonesD() do
        dR = complex.(x.dRre, x.dRim)
        dL = complex.(x.dLre, x.dLim)
        return gR, gL
    end
julia> R = JonesR()
julia> J = JonesSandwich(G, D, R)
julia> intprior = (lgr = ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, 0.1)),
                    gpr = ArrayPrior(IIDSitePrior(ScanSeg(), DiagonalVonMises(0.0, inv(π^2))),
                    lgrat = ArrayPrior(IIDSitePrior(ScanSeg(), VLBIGaussian(0.0, 0.1)),
                    gprat = ArrayPrior(IIDSitePrior(ScanSeg(), DiagonalVonMises(0.0, inv(π^2))),
                    dRre = ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, 0.1)),
                    dRim = ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, 0.1)),
                    dLre = ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, 0.1)),
                    dLim = ArrayPrior(IIDSitePrior(TrackSeg(), VLBIGaussian(0.0, 0.1))
                    )
julia> intm = InstrumentModel(J, intprior)

which construct the gain matrix from R and ratios, and D is the small leakage matrix. JonesR is the response matrix that controls how the site responds to the ideal visibility in the reference basis.

Comrade.ReactantNUTS Type
julia
ReactantNUTS(; kwargs...)

Experimental NUTS sampler that runs through Reactant's ProbProg mcmc_logpdf. Like AdvancedHMC's NUTS, all sampler configuration lives in the struct.

Warmup runs Stan's windowed adaptation: fixed init_buffer = 75, term_buffer = 50, base window 25, doubling, with the same 15%/10% fallback when the buffers don't fit — one continuous Nesterov dual-averaging step-size process (γ=0.05, t₀=10, κ=0.75, target accept 0.8) plus a Welford diagonal mass matrix updated at window ends.

Warmup is executed in chunks, by default the same size used for sampling (saveto.stride for a DiskStore, otherwise the chunk_size passed to sample; override with sample's warmup_chunk). The ProbProg backend anchors the windowed schedule to the global warmup length (total_warmup/warmup_offset), so chunking is bit-identical to one fused warmup whatever the chunk length. When sampling to a DiskStore, the adaptation state is checkpointed every checkpoint_every warmup steps, so an interrupted warmup can be resumed with restart = true, and one draw per chunk is logged to <name>/warmup for inspection.

Keyword arguments

n_adapts = 1000 total warmup steps; the internal Stan windowed schedule is derived from this by the ProbProg backend. init_step_size = 0.01 initial leapfrog step size; seeds dual averaging (see note) max_tree_depth = 10 max_delta_energy = 1000.0 strong_zero = true turn 0_Inf / 0_NaN in the gradient into 0; REQUIRED for stiff image models or every proposal NaN-rejects and the chain freezes – keep true unless you know better.

Differences from AdvancedHMC's NUTS

Two pieces of AdvancedHMC's setup are not (yet) reachable through ProbProg:

  • No find_reasonable_step_size. AdvancedHMC seeds dual averaging from find_good_stepsize; ProbProg has no such heuristic and instead anchors dual averaging at init_step_size (its prox-center is log(10*init_step_size)). Pick init_step_size in the right ballpark for your problem.

  • Target acceptance is fixed at 0.8 in the backend (matching NUTS(0.8)'s default) and is not currently configurable.

Comrade.check_move Function
julia
check_move(move, post, θs; space = nothing, rng = Random.default_rng(), τ = 0.1,
           rtol = 1e-8, h = 1e-6, logdet_atol = 1e-5, nprior = 0, nsteps = 5,
           ncoords = 5, ks_alpha = 1e-3, ngeweke = 0, geweke_steps = 10) -> NamedTuple

Test move on post in the latent space space, at each parameter point in θs, with steps at scale τ. Throws an error naming the first failed check:

  • reversal: the reverse step from the proposal returns to the start, with the opposite log-determinant;

  • log-determinant: logdet matches a finite-difference Jacobian (step h);

  • invariance: if likelihood_invariant(move), the log-likelihood is unchanged;

  • components: for a ComponentwiseNormalStep move, the components are independent: disjoint coordinates, and component i of the step changes only component i.

Two optional tests compare samples with two-sample Kolmogorov–Smirnov tests at level ks_alpha, on up to ncoords of the coordinates the move changes:

  • nprior > 0: nprior prior draws each take nsteps steps of the move targeting the prior, and are compared with fresh prior draws.

  • ngeweke > 0: Geweke's (2004) joint-distribution test of the kernel MoveSet runs. Each of ngeweke replicates draws parameters from the prior and data from the model (simulate_observation), then alternates geweke_steps move steps with new data. The results are compared with fresh draws of parameters and data, also along the move's direction and on the log-likelihood. Arrays in the move context are not rebuilt for the new data.

Returns the largest reversal error, log-determinant error and log-likelihood change; the KS statistics ks and geweke with their critical values; and geweke_accept, the acceptance rate in the Geweke test. A move that rarely moves passes the Geweke test untested, so check that geweke_accept is not near zero.

Compute the source elevation and parallactic angle at a single antenna and time.
